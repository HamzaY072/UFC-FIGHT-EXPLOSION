UFC Fight Explosion
Project Overview
UFC Fight Explosion is a Processing project that uses UFC fight data to display information about fights and their statistics.

Dataset
The project includes a spreadsheet containing UFC main card fight data from 2024.

Features
Displays a UFC Fight Explosion interface.
Uses red and blue corners to represent the fighters.
Processes fight statistics, including knockouts, submissions, decisions and significant strikes.
Uses data to calculate totals and summarise fight information.

Technologies Used
Processing
Java-based Processing code
Microsoft Excel
GitHub
